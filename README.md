# GeoDesiC-Hexrotor

Active research documentation for hexrotor drone

## Project Overview

This project investigates how three pairs of passively sensed dual rotor joints can be used in tandem in a tilt-rotor aerial vehicle. In this tightly coupled system, rotors influence both joint angle and overall flight direction, which we hope can improve the efficiency, stability, and responsiveness of multi-rotor systems compared to traditional fixed-frame aerial vehicles.

The repo is organized by subsystem. The current subsystems are:
1) [Electrical System + Controls](./Electrical%20System/README.md): Includes the sensing and embedded hardware side of the platform.
2) [Pydrake Model](./Pydrake%20Model/README.md): Includes the Pydrake model.
